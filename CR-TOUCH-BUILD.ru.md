# Заметки по сборке и калибровке Ender-3 / Creality v4.2.7 + CR-Touch

[English](CR-TOUCH-BUILD.md) | [繁體中文](CR-TOUCH-BUILD.zh-TW.md) | Русский

Прошивка собрана на базе **Marlin 2.1.2.10** с использованием официального
примера конфигурации `Creality/Ender-3/CrealityV427`; настройки CR-Touch перенесены
из предыдущей конфигурации.

## Сборка

```bash
python3 -m venv .venv
.venv/bin/pip install platformio
.venv/bin/pio run -e STM32F103RE_creality
```

Результат: `.pio/build/STM32F103RE_creality/firmware.bin`.
Готовые к прошивке копии находятся в [`firmware/`](firmware/).

## Настройки платы и датчика

- `MOTHERBOARD BOARD_CREALITY_V427` — 32-битная плата Creality 4.2.7
- `#define BLTOUCH` — CR-Touch является совместимым клоном BLTouch
  - Сигнал датчика: `PB1` (`Z_MIN_PROBE_PIN`, 5-контактный разъём датчика)
  - Серво/привод: `PB0` (`SERVO0_PIN`)
- `#define BLTOUCH_DELAY 500` — дополнительная задержка команд для клона
- `NOZZLE_TO_PROBE_OFFSET { -30, 0, 0 }` — измерено по «живому» `M851` принтера
  (`X-30.00 Y0.00 Z-1.38`); X/Y соответствуют физическому креплению, Z
  калибруется заново после прошивки
- `#define AUTO_BED_LEVELING_BILINEAR`, сетка 5×5
- `#define Z_SAFE_HOMING`
- `PROBING_MARGIN_LEFT/RIGHT 35`, `FRONT/BACK 15` — чтобы смещённый датчик
  оставался в пределах стола
- `#define BABYSTEP_ZPROBE_OFFSET` — оперативная подстройка Z-смещения
- `#define PROBE_OFFSET_WIZARD` — калибровка Z-смещения мастером на LCD
  (`PROBE_OFFSET_WIZARD_START_Z -1.0`)
- `Z_MIN_POS -5` — исправляет проблему «сопло не достаёт до стола»: при
  отрицательном Z-смещении (`M851 Z-1.38`) сопло должно опускаться ниже Z=0,
  а стандартное ограничение `Z_MIN_POS 0` это запрещало
- `Z_MAX_POS 350` — намеренно: на принтере установлен физический **комплект
  удлинения оси Z** (профили «Z350», официальная прошивка называется
  `Ender-3 HD4.2.7-Z350-...`). Не уменьшайте до стандартных 250.
- `BINARY_FILE_TRANSFER` + `CUSTOM_FIRMWARE_UPLOAD` — возможность бинарной
  передачи Marlin (практические ограничения — ниже)
- `OTA_FIRMWARE_UPDATE` + `M936` — обработчик команды Creality MCU-OTA.
  `M936 V2` теперь отвечает `mcu reset ok` перед перезагрузкой, как ожидает бокс.

## Прошивка

Плата 4.2.7 загружается с файла `.bin` в корне SD-карты FAT32.

1. Скопируйте **один** файл прошивки `.bin` в корень карты.
2. Дайте ему **новое уникальное имя** — загрузчик Creality запоминает предыдущее
   имя и не прошивает то же имя дважды.
3. Убедитесь, что на карте **нет других файлов `.bin`** (неполный `.bin` после
   неудачной передачи может быть прошит по ошибке).
4. Выключите принтер, вставьте карту, включите питание и дождитесь окончания
   обновления.
5. Извлеките карту и перезагрузите принтер.

Проверьте `M115` (должно быть Marlin 2.1.2.10) и `M211`
(должно быть `Zmin -5.00`, `Zmax 350.00`).

## После прошивки (важно)

1. `M502`, затем `M500` — сбросить настройки к значениям прошивки.
2. `G28` — парковка всех осей; `M401` / `M402` — выпустить/убрать датчик и
   убедиться, что CR-Touch работает.
3. Установите Z-смещение, например `M851 Z-1.38`, затем `M500`.
   Либо используйте мастер на LCD: **Motion → Bed Leveling → Probe Offsets (Wizard)**.
   (`Z` в `NOZZLE_TO_PROBE_OFFSET` — лишь исходное значение.)
4. Выполните `G29` для построения сетки, затем `M500` для сохранения.
5. Тонко подстройте первый слой во время печати с помощью babystepping.

### Устранение неполадок датчика

- Датчик не выдвигается: `M280 P0 S10` (выпустить) / `M280 P0 S90` (убрать),
  проверьте коричневый, красный и оранжевый провода.
- Нет срабатывания: проверьте чёрный и белый провода.
- Нестабильное зондирование: увеличьте `BLTOUCH_DELAY` или включите
  `BLTOUCH_FORCE_SW_MODE` в `Marlin/Configuration_adv.h` и пересоберите прошивку.

## Удалённое обновление через WiFi-бокс Creality

Теперь удалённая прошивка работает через бокс по протоколу Marlin BFT.
Процедура описана в [README.ru.md](README.ru.md#wifi-бокс-creality-и-удалённое-обновление).
Инструменты находятся в [`tools/`](tools/): `gen_bft.py` подготавливает пакеты,
`bft_daemon.sh` работает на боксе, `box_telnet.py` и `printer_gcode.py` —
вспомогательные сценарии для shell и G-code.

## Дополнительно

Если ваше крепление CR-Touch имеет другие смещения X/Y, измените
`NOZZLE_TO_PROBE_OFFSET` в `Marlin/Configuration.h`, пересоберите прошивку и
выполните калибровку заново.
